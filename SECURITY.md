# Security Policy

## Purpose

This repository is an educational CTF walkthrough for an isolated TryHackMe environment.

## Reporting

Please do not submit real-world credentials, secrets, personal information or live-system data through repository issues.

For documentation concerns, use a GitHub issue with a minimal reproducible description and remove any sensitive values before posting.

## Public Release Hygiene

Flag values, recovered passwords and reusable NTLM material are intentionally redacted from the public portfolio documentation.
